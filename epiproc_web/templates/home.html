Plataforma de vigilancia epidemiológica

EPIPROC - Procesamiento Epidemiológico

Sistema para analizar, monitorear y comunicar información epidemiológica del departamento. El acceso público permite visualizar el comportamiento del evento y consultar boletines en modo lectura.

Ver dashboard Ver boletines {% if not current_user %} Ingresar al sistema {% endif %}

¿Qué permite este software?

  • Visualizar indicadores y gráficas del evento en un solo panel.
  • Consultar datos depurados con actualización continua.
  • Aplicar filtros por municipio para análisis territorial.
  • Publicar y consultar boletines epidemiológicos de forma controlada.
  • Gestionar perfiles de trabajo para Secretaría y Epidemiología.

Flujo de operación del sistema

  1. Ingreso y depuración del archivo epidemiológico.
  2. Consolidación de métricas y distribución territorial.
  3. Visualización en dashboard con filtros operativos.
  4. Generación y publicación de boletines.

La visualización se alimenta de la fuente depurada activa para mantener coherencia en todo el sistema.
